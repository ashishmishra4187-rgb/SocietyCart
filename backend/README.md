# SocietyCart Backend

Spring Boot 3.3 / Java 21 / PostgreSQL / Flyway / STOMP WebSocket.

See **BACKEND_REVIEW.md** for the review, the fixes, how to run, and what has/has not been verified.

```bash
mvn spring-boot:run     # dev profile by default; create an account in the UI (OTP 123456 in dev), or use 9000000001 (admin) / 9000000002
mvn test
```
